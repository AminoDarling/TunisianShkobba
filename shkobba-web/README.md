# Shkobba (شكبة) — web app

Tunisian card game with 2 or 4 players (2 vs 2), vs the computer or with friends over Wi-Fi.
Made with love by aminodarling and Claude.

## Run it
1. Install Node.js (version 16 or newer) from https://nodejs.org
2. In this folder run:  `node server.js`
3. Open the address it prints. Tap **Host a game**, choose 2 or 4 players.
4. Friends on the same Wi-Fi (or your hotspot) open the "Friends on your Wi-Fi" address in any browser.

No packages to install. Use another port with `PORT=3000 node server.js`.
It also runs on an Android phone with Termux (`pkg install nodejs`), and on any Node host such as Render or Railway for play over the internet.
